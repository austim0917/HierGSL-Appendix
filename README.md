# HierGSL: Supplementary Appendix

This repository hosts the supplementary appendix to the paper:

**Hierarchical Graph Swarm Learning for Personalised and Energy-Efficient Edge Intelligence**

**Authors:** Jianing Zheng, Xiaolan Liu, and Jiadong Yu.

The appendix provides additional theoretical analysis, proofs, empirical evaluations, and experimental details for the HierGSL framework.

## Read the Appendix

**[Open the appendix (PDF)](./Appendix.pdf)**

## Contents

| Section | Topic |
| --- | --- |
| A | Conditional convergence bounds under time-varying communication graphs, including empirical aggregation-matrix diagnostics |
| B | Formal game-theoretic models for intra-cluster and inter-cluster interactions |
| C | Proofs of equilibrium existence |
| D | Communication decision complexity of the hierarchical graph structure |
| E | Existence of a hierarchical equilibrium in the finite extensive-form game |
| F | Optimality gap of the two-stage decomposition |
| G | Empirical association between the heuristic scheduling utility and one-round local performance change, with a validation-gain utility comparison |
| H | Experimental setup, including non-IID data partitioning and heterogeneous device initialization |
